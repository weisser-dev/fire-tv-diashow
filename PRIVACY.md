# Privacy Policy — Fire TV Diashow

Last updated: November 23, 2026

Fire TV Diashow displays images that you choose. It has no account service, advertising, or analytics. Google Photos login and API integrations are not included.

## Images and device data

When you choose files, Android grants the app read access to those files. The app stores the selected file references and playback preferences on the device. The original files stay in their locations.

When you use the phone upload, the app temporarily starts a web server on the local network while the app is running. The phone sends image files directly to the TV, where they are kept in the app's private storage. The app does not send them to the developer. The QR link is random and temporary; uploads are accepted only from local network addresses. An optional PIN can add another upload check.

The QR management page can also download a frame backup to your phone. This unencrypted ZIP contains copies of the selected photos, album names, hidden-photo choices, viewing counts, settings, calendar subscription address, notes, and tasks. The device PIN stays on its TV. Restoring a backup replaces the destination frame’s library after the app validates the transfer.

If you enable weather, the app sends the country code and postal code you enter to Open-Meteo geocoding and forecast endpoints to retrieve current public weather data. No photo data is part of those requests. See [Open-Meteo's privacy information](https://open-meteo.com/en/terms).

The update checker contacts the public GitHub Releases API to find newer versions. If you choose to download one, the APK comes from the public GitHub release.

## Retention and deletion

File references, uploaded images, albums, and preferences stay on this device until you delete them or uninstall the app. Clearing an album or deleting images removes the app's local copies.
