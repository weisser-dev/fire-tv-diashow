APK herunterladen und installieren

Öffne im Downloader diese Adresse, lade die APK und erlaube dem Downloader bei Nachfrage die Installation unbekannter Apps:

https://github.com/weisser-dev/google-photos-carousel/releases/latest/download/app-release.apk

Für lokale Bilder wählst du auf Android TV verfügbare Ordner oder Dateien aus. Die Google-Fotos-Albumverbindung erfordert zusätzlich eine aktivierte Ambient API und einen passenden OAuth-Client.
